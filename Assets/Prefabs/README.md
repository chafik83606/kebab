# Prefabs

Créer dans l'éditeur Unity :

1. **Restaurant.prefab** — GameObject avec `RestaurantManager`, `EmployeeManager`, `StockManager`, `HygieneVisualController`.
2. **Fly.prefab** — petite sphère + `FlyMover` (référencée dans `flyPrefabs[]`).
3. **DirtStain.prefab** — quad/décal saleté (référencée dans `dirtStains[]`).

Le menu **Kebab Empire → Setup Main Scene** génère des placeholders de test directement dans la scène.
